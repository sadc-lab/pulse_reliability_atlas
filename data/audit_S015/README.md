# S015 audit artifacts

Outputs from the pre-publication reproducibility and logic audit
(`experiments_log/santino/S015_reproducibility_and_logic_audit.md`,
2026-05-04). Committed as the on-disk evidence behind the audit's
"EXACT, 0 diff" claims, so a reviewer can inspect the regenerated
artifacts without re-running the full sweep.

These are audit *copies* — the canonical artifacts driving the paper
live in `results/` and `data/runs/full_sweep/`. Files here were
re-generated by `tests/audit_S015/regen_compare.py` from
`data/runs/full_sweep/morris_sample.parquet` + `src/scenario.py` and
compared against `results/` for byte- or value-exact equality.

Phase 1.4 (re-derived analytic artifacts):

* `full_sweep_aggregated.parquet` — regenerated master sweep table
  (audit copy, not the canonical one in `results/`).
* `cell_flag_summary.csv`, `morris_indices.parquet`,
  `h1_top3_fraction.csv`, `sobol_promotion.csv`,
  `wasserstein_male_vs_female.csv`, `spearman_mu_star.csv`,
  `clamp_grid.parquet`, `diverged_grid.parquet`,
  `reliability_classification.csv` — all derived analytic outputs,
  each EXACT against `results/` (see S015 §1.4 result table).
* `regen_compare.log` — full Phase 1.4 stdout.

Phase 2 (subset re-execution, 40 runs):

* `subset_repro.log` + `subset_repro_report.json` — bit-exactness
  check of 40 re-executed Docker runs (cases drawn from each
  scenario / sex / divergence regime). All match within tolerance.
* The 40 re-execution directories themselves are not committed (per
  `.gitignore data/runs/**/*` rules) but are listed in the report.

Phase 3 (math isolation / fuzz):

* `p31_positive_control.log` — synthetic-EE known-answer test.
* `p31_synthetic/baseline.csv` — minimal fixture input for P3.1.
* `p32_negative_control.log` — corrupted-input rejection check.
* `p33_math_isolation.log` — hand-built EE math vs. SALib agreement.
* `p34_boundary_fuzz.log` — detector flag-bound stress test.

Total directory: ~600 KB. Provenance and interpretation: see the
S015 log linked above.
